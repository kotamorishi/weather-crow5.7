Weather Crow

ESP32-S3 E-Paper Weather Display v5.7

Install Firmware

Your browser doesn't support Web Serial.
Please use Chrome, Edge, or Opera on desktop.

Requirements

  • Chrome, Edge, or Opera browser
  • USB cable connected to your ESP32-S3
  • Windows, macOS, or Linux

How to Install

  1. Connect your ESP32-S3 device via USB
  2. Click the Install Weather Crow button above
  3. Select the serial port for your device
  4. Wait for the installation to complete (~30 seconds)
  5. Your device will restart and start the WiFi setup
⚠️ First boot: The device will create a WiFi hotspot called WeatherCrow-Config. Connect to it and go to 192.168.4.1 to configure WiFi and your OpenWeatherMap API key.
